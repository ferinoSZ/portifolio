Sobre mim

Sempre tive interesse por tecnologia, computadores e videogames, mas inicialmente não imaginava seguir carreira em programação. O contato com programação durante a escola despertou meu interesse, que foi evoluindo ao longo do tempo.

Comecei minha trajetória pelo Frontend, explorando a criação de interfaces e experiência do usuário. Depois, meu interesse se expandiu para a integração entre Software e Hardware, buscando compreender como os sistemas se conectam com o mundo físico.

Foi na Inteligência Artificial que encontrei a área que mais me motiva. A possibilidade de utilizar IA para resolver problemas reais e criar sistemas mais inteligentes é o que me impulsiona a aprender e evoluir constantemente.

Busco sempre unir teoria e prática, desenvolvendo soluções simples, claras e úteis, com foco em aplicar IA de forma concreta em sistemas de software. Sou flexível diante do que ainda não domina: toda tecnologia nova é uma ocasião para aprender rápido.

Processamento de PDFs com RAG

IA Aplicada Concluído

Sistema no qual o usuário fornece um PDF e realiza perguntas utilizando linguagem natural. O sistema utiliza embeddings para localizar informações semanticamente relacionadas ao conteúdo do documento e fornecer respostas precisas e contextualizadas ao usuário.

Desenvolvido com foco em documentos relacionados ao ambiente universitário.

Tecnologias utilizadas:

Python Chunking Embeddings RAG

Sistema Financeiro com IA

IA Aplicada Em Desenvolvimento

Sistema financeiro em desenvolvimento com integração à API do Telegram. Utiliza embeddings para realizar a categorização automática de determinados gastos, além de permitir a geração de relatórios organizados por período e categoria.

Visa automatizar o controle financeiro de forma inteligente, reduzindo o trabalho manual na organização de despesas.

Tecnologias utilizadas:

Python Telegram API Embeddings Machine Learning
